# Echo-lite

Echo-lite is a small rule-based Python assistant built for
the SHOCK 101 Git mini-project.

## Features
- Accepts a text message
- Returns a simple response
- Handles empty input
- Runs without API keys or external dependencies

## Requirements
- Python 3.10 or newer

## Run
python echo_lite.py

## Example
Input: Hello
Output: Echo-lite received: Hello

## Project Goal
Practice Git commits, branches, issues, pull requests,
merge conflicts, tags, and secure repository management.
